# Contributing

Contributions are welcome.

## Guidelines

- Keep the Excel input format documented.
- Preserve deterministic behavior when a random seed is configured.
- Add or update tests/examples when changing selection logic.
- Do not commit real alliance member data or other personal/private information.
- Explain rule changes clearly in pull requests.

## Pull requests

Describe:

1. What changed.
2. Why it changed.
3. Which DSB rule is affected.
4. How the result was tested.
